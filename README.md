# Bildmakaren

Gör bilder med blisstext, foton och geometriska figurer – med knappar som är Bliss-symboler.
För personer med fysiska funktionsnedsättningar och datorhjälpmedel: pekskärm, ögonstyrning
(välj genom att titta), en eller två kontakter med scanning och tangentbord.

Av John Säbom. Symbolerna ritas med BlissEngine av P-O Hedvall och Jonas Paulsson (AnyCom AB) –
ritmotorn ur WinBliss.

Fungerar i webbläsaren och kan installeras som app (iPhone/iPad: Safari → Dela → Lägg till på
hemskärmen; Android och dator: Chrome/Edge → Installera app). Installerad fungerar den utan internet.

**Öppna appen:** https://johbom.github.io/bliss-bildmakaren/

## Integritet

- Allt stannar på den egna enheten. Appen skickar inget till någon server – sidans säkerhetsregler
  (Content Security Policy) stoppar alla anrop till andra adresser.
- Ingen inloggning, ingen statistik, inga kakor, inga externa typsnitt eller skript.
- Kameran används bara när man trycker på kamera, och stängs när appen läggs undan.
- Uppläsningen använder bara röster som finns på enheten – texten skickas aldrig till någon taltjänst.
- Elevernas namn (om man lägger upp elever) finns bara på enheten. Tar man bort en elev försvinner
  namnet, inställningarna och elevens alla bilder.
- Foton sparas om i appen, så att plats (GPS) och annan dold information i bildfilen försvinner.
- Bilderna sparas i webbläsarens lagring på enheten. De kan raderas en och en, eller allt på en gång
  under Inställningar → Radera allt på enheten.
- Det man själv lägger in, delar eller skriver ut ansvarar man själv för.
